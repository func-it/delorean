Architecture

The stack and its exchanges

A cart written in free text leaves the browser, goes through the BFF, then through the API, which reads it in six stages. The models read, through OpenRouter; the code counts and sets the price; every request leaves a trace in Langfuse.

What POST /v1/quotes does with example 5 of the brief: the three volumes and La chèvre. Every stage may refuse the cart with a stable code; the models never set an amount.
